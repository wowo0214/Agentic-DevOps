# Why real equipment changes the lesson

> A controller can be correct in a model and still surprise you on a physical system. That gap is where the most useful experiments begin.

## The model is a map

A simulation gives a control idea a clean place to start. It makes assumptions visible, parameters easy to change, and the first iteration quick to repeat.

That clarity is valuable. It also leaves some details outside the frame: friction, sensor noise, actuator limits, delay, and the small imperfections that accumulate in a real mechanism.

## The physical system answers back

On equipment, the same algorithm meets those details at once. A response can overshoot a little more, settle later, or expose a limit that was invisible in the ideal model.

That difference is not a failure of simulation. It is the next piece of evidence. Students can compare the expected curve with the measured one and ask which assumption needs to change.

## A better loop for learning

M2PLink connects the control blocks students already understand with remote laboratory equipment. Design in blocks, inspect the model, run the experiment, then bring the measurement back into the next iteration.

The goal is a practical habit: treat simulation as a hypothesis and the physical experiment as a careful test.
